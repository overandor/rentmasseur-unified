AUTHORITY

Lease, not chat identity

The ChatGPT conversation id is a label. Access comes from a valid device signature, private matching record, disposable token, exact grant, live state, and owner approval.

EXPIRATION

Atomic states

Open, waiting, used, expired, revoked, destroyed. There is no ambiguous permission decay or zombie mailbox.

EVIDENCE

Receipts, not consciousness

A signed receipt proves a handled request and result commitment. It does not prove model understanding, attention, or wisdom.

Deployment boundary

The endpoint code is implemented locally. A publicly reachable guardian still requires an owner-chosen domain or tunnel, an explicit TLS certificate/key, and platform-side GPT Action or MCP registration. MirrorLease does not invent or install those credentials silently.
