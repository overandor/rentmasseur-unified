Mechanism status

The runnable path is local.

The command below creates the same signed invitation the Finder helper uses. It writes the private lease under Application Support and prints the public mirrorlease:v1: token that can be pasted into an AI session.

python -m mirrorlease_protocol.local_cli create /path/to/file --clipboard
01

Private record

~/Library/Application Support/MirrorLease/leases/<id>.json stores the local path, file hash, exact grants, token hash, expiration, and signed lease metadata.

02

Gateway

python -m mirrorlease_protocol.local_cli serve --port 9443 exposes the same knock, request, receipt, and MCP adapter on localhost for testing.

03

Approval gate

Reads and summaries call back to the owner Mac. The normal path opens a macOS Allow once / Deny dialog before file content is disclosed.
