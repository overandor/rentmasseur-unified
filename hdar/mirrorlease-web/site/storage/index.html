No hand-waving

Where does my file reside?

Exactly where you saved it. MirrorLease records a private mapping; it does not silently move the original into the website, a wallet, a blockchain, or an AI provider.

The storage map

PRIVATE KEY

Local owner key

Finder helper: macOS Keychain. Local CLI smoke path: ~/Library/Application Support/MirrorLease/keys/ with private file permissions.

Clipboard

A public, disposable mirrorlease:v1: invitation: public file identifiers, exact grants, challenge, expiration, issuer public key, signature, and one-use lease capability. No raw local path. No device private key.

Audit trail

~/Library/Application Support/MirrorLease/audit.jsonl contains hash-linked, device-signed receipts for knocks, approvals or denials, requests, expiration, revocation, and destruction.

Website boundary

This public website explains the product and protocol. It has no route that accepts your private file and no storage binding for lease content. The actual access path is the owner-machine guardian and its signed lease record.
