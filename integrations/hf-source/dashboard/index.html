Proof, not promises

Every action is backed by a cryptographic receipt. You can verify the work was done — yourself, independently.

How the proof chain works

1. Screenshot captured at the exact moment of action (visit, bio update, availability check)
2. Timestamp, URL, session ID, and page content hash embedded into the image as a visible overlay
3. SHA-256 hash computed from screenshot bytes + metadata
4. Each hash chained to the previous action's hash — tamper-evident, can't insert or replay
5. Receipt written with: proof hash, previous hash, timestamp, URL, page hash, API response data
6. Verification checks: file exists, hash matches, chain unbroken, timestamp valid, API data present
